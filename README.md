# nao-viewer

MuJoCo viewer for NAO: mirrors any NAOqi robot, or renders nao-local's simulated world. It also holds the NAO model and a license-gated mesh fetcher.

Unofficial and not affiliated with Aldebaran. The code is MIT. The NAO meshes are **not** shipped here: they are Aldebaran's work under CC BY-NC-ND 4.0 (**non-commercial**), and each user fetches them locally after accepting the license.
