# Viewer window

**Status:** Done

Implements [specs/viewer.md](../specs/viewer.md): `ViewerState` (posing from a pose source, status overlay, ghost, attribution, keys) and `run` on MuJoCo's passive viewer, plus the `name` argument of `load_world` ([specs/model.md](../specs/model.md)) that sets the window title. It leaves out an automated test of the window itself: `run` needs a display and `mjpython`, and gets its live-tier test with `launch` ([specs/api.md](../specs/api.md)), which is how it will be started.

Checks against MuJoCo 3.15 settled three spec points first:

- `launch_passive` has no title argument; the window is titled `MuJoCo : <model name>` (read back from the window under `mjpython`), so the title is set through the compiled model's name.
- `Handle.set_texts` takes plain text: no per-line color, so the `STALE` text is the stale marker (former open question 1).
- Every letter and digit is a MuJoCo viewer shortcut, and keys reach both MuJoCo and `key_callback`: the status toggle moves to `F9`, and the attribution loses its toggle.

## Steps

1. `load_world(name=...)`: set `MjSpec.modelname` before compiling.
2. `ViewerState(model, source, *, ghost, attribution)`:
   - `update()`: pose `data` with `PoseWriter` when the latest sample's `seq` is new; pose a second `MjData` from `sample.commanded` for the ghost.
   - `draw_ghost(scene)`: `mjv_addGeoms` with only geom group 1 and `mjCAT_DYNAMIC` (robot visuals, no floor), recolored translucent; bodies whose commanded pose is within 1 mm / ~0.5° of the measured one get alpha 0. Found in the first window run: drawing every body tinted the whole robot blue, since the ghost sits exactly on it wherever commanded = measured.
   - `texts(now)`: status lines top-left (target + URL, NAOqi version or `unknown`, rate, data age / `STALE` past 500 ms / `NO DATA`; `connecting` before the first connection), attribution bottom-right when given.
   - `on_key`: `F9` (GLFW 298) toggles the status overlay.
3. `run(model, source, *, ghost, attribution, on_frame)`: `launch_passive` with both panels hidden and `on_key` as key callback; tracking camera on `torso`; loop while the window is open: under `handle.lock()` update and draw the ghost into `user_scn`, set the texts, call `on_frame`, `sync`, sleep to the next 1/60 s tick on a fixed schedule.

## Verification

- `tests/test_viewer.py`: new samples pose the model and repeated ones don't; the status lines in each state (connecting / no data, fresh age in ms, `STALE`, unknown version); `F9` toggles the overlay and a letter doesn't; the attribution appears only when given; the ghost shows exactly the bodies off their commanded pose (the right arm when only `RShoulderPitch` differs), nothing when they match, and nothing without commanded angles or with `ghost=False`; ghost geoms are always robot visuals.
- `tests/test_model.py`: `load_world(name=...)` names the compiled model.
- By hand, under `mjpython` against the mock NAOqi: the window title, the overlay (nao-sim, 0.3.0, 50 Hz, a few ms of data age), the ghost arm, ~50 frames per second.
