# Continuous integration

**Status:** Done

Implements [specs/ci.md](../specs/ci.md): the three-job workflow (`check`, `fast-tier`, `e2e-nao-sim` on nao-sim's NAOqi 2.1), and the test changes it needs ([specs/testing.md](../specs/testing.md)). It leaves out a NAOqi 2.8 entry and Docker layer caching (ci.md open questions).

## Scope

- `.github/workflows/ci.yml`: new, the three jobs
- `pyproject.toml`: `specs/` and `plans/` excluded from ruff, so `ruff format --check .` is the whole-repo check
- `tests/test_viewer_process.py`: `no_offscreen_gl(reason)` skips, or fails when `NAO_VIEWER_REQUIRE_OFFSCREEN_GL` is set; both GL-gated tests use it
- `tests-e2e/test_viewer_live.py`: the head-moving helpers open their sessions with `nao_viewer.source.connect` (retries), after a bare connect failed once against a freshly booted nao-sim
- `specs/ci.md` (new), `specs/testing.md`, `specs/_index.md`, `AGENTS.md` (project map row for `.github/workflows/`), this plan, `plans/_index.md`

## Steps

1. Ruff exclusion; check that `ruff format --check .` passes with no Markdown churn.
2. The GL switch in the fast tier.
3. The live helpers on `connect`.
4. The workflow:
   - `check`: sync, lint, format, types.
   - `fast-tier`: apt Mesa's EGL, then `pytest -rs` with `MUJOCO_GL=egl` and `NAO_VIEWER_REQUIRE_OFFSCREEN_GL=1`.
   - `e2e-nao-sim`: check out nao-sim at `NAO_SIM_REF`, apt Mesa's EGL, restore the vendor cache, `nao-sim fetch-and-build-images 2.1`, save the cache, `docker compose --profile 2.1 up -d --wait --no-build`, `pytest tests-e2e -rs` with `NAOQI_URL`, and the NAOqi logs on failure.
5. Statuses, once the first run on GitHub is green: this plan `Done`, ci.md `Implemented`.
