# Pose source and mock NAOqi

**Status:** Done

Implements [specs/source.md](../specs/source.md) (`connect`, `Sample`, `TargetInfo`, `PoseSource`, `NaoqiSource`) and the mock NAOqi of [specs/testing.md](../specs/testing.md) ("Mock NAOqi"), which brings testing.md back to `Implemented`. It leaves out the live-tier tests against a real NAOqi, which come with the viewer.

A spike settled the mock's transport first: the libqi 3.1.6 fork serves Python services from a standalone `qi.Session` (`listenStandalone("tcp://127.0.0.1:0")`, `registerService`), plain methods need no `@qi.bind`, a missing service raises `RuntimeError`, closing the server disconnects clients, and a new server rebinds the same port at once (0 failed connects out of 30).

## Steps

1. **`MockNaoqi`** (`tests/mock_naoqi.py`):
   - `MockNaoqi(target="virtual"|"nao-sim"|"real", version=...)`: `start()` listens on a free loopback port and registers the services; `url`; `close()`.
   - `ALMotion`: `getBodyNames("Body")` → `JOINT_NAMES`; `getAngles(names, useSensors)` with `names` `"Body"`, a joint name or a list, from the measured or the commanded angles; `getTransform(name, frame, useSensors)`: `"Torso"` in world frame (1) from the set torso transform; `Head`/`LArm`/`RArm`/`LLeg`/`RLeg` in torso (0) or world (1) frame, from the forward kinematics of `load_world()` posed with `PoseWriter`, plus an optional per-effector error transform; `setStiffnesses`; `angleInterpolation(names, angles, times, isAbsolute)` sets measured and commanded angles at once.
   - `ALMemory`: `getData`, `insertData` on a dict. `NaoSim` (registered for `nao-sim`, with `NaoSim/Version` in memory) and `ALSystem` (registered for `real`, `systemVersion()`).
   - Test controls: `set_pose(angles, torso_transform=None, commanded=None)`, `set_effector_error(name, transform)`, `fail_calls(exc_message | None)` (every `ALMotion` call raises), `disconnect()` (closes the server), `restart()` (serves again on the same port, services re-registered), `calls` (recorded `(service, method, args)`).
   - Thread-safe: qi calls services on its own threads, so state sits behind a lock.
2. **Fixture** (`tests/conftest.py`): `mock_naoqi` starts a `virtual` mock and yields `(url, mock)`, closing it afterwards. Other targets are built directly with `MockNaoqi(target=...)`.
3. **`source.py`**:
   - `connect(url)`: normalize `host` → `tcp://host:9559`; try `qi.Session().connect` up to 5 times, sleeping 0.2, 0.4, 0.8, 1.6 s between tries; raise `ConnectionError` with the URL and the last qi error.
   - `Sample`, `TargetInfo` frozen dataclasses; `PoseSource` `Protocol`.
   - `NaoqiSource`: a daemon thread runs `connect → identify → poll` and, on a qi error, a failed connect or a malformed reply (`RuntimeError`, `ConnectionError`, `ValueError`, `IndexError`, `TypeError`; anything else is a bug and surfaces), drops the session and retries after a backoff (0.5 s doubling to 5 s, reset after a successful connection); `close()` sets a stop event, joins the thread and closes the session. Sleeps use the stop event so `close()` is prompt.
   - Identify: `session.services()` names → `nao-sim` (`ALMemory.getData("NaoSim/Version")`), `real` (`ALSystem.systemVersion()`) or `virtual` (`None`).
   - Poll tick: `getAngles("Body", True)` zipped with the connection's body names (known ones only), `getTransform("Torso", 1, True)`, and with `commanded=True` `getAngles("Body", False)` with the same torso; `NaoPose.from_naoqi`; publish a new `Sample` (next `seq`, `received_at=time.monotonic()`) by swapping one attribute, and record the time for `rate()`. Pacing: ticks are due on a fixed schedule (found while testing: timing from each tick's start ran at ~43 Hz, because `Event.wait` oversleeps ~3 ms on macOS); an overrun starts the next tick immediately and restarts the schedule.
   - `rate()`: samples received in the last second.
4. **Docs**: AGENTS.md project map; statuses: source.md `Implemented`, testing.md `Implemented`, this plan `Done`.

## Verification

`tests/test_source.py`, against the mock:

- **Samples**: the latest sample carries the mock's angles (by name) and torso pose; `seq` increases from 1; `latest()` is `None` before the first sample (unreachable URL); `rate()` is close to `rate_hz`.
- **Commanded**: with `commanded=True` the sample's `commanded` holds the commanded angles, with the same torso; without, it is `None`.
- **Unknown names**: a body name the model doesn't know is left out of the pose and logged once.
- **Target identification**: `virtual`, `nao-sim` and `real` mocks give the right `target` and `naoqi_version`; `info` is `None` before connecting.
- **Robustness**: when every call fails, `latest()` keeps returning the last sample and its age grows; after `disconnect()` + `restart()`, the source reconnects, re-reads the target, and samples resume with increasing `seq`; a source started before the mock exists connects once it appears.
- **Read-only**: the mock records no `setStiffnesses`/`angleInterpolation` calls from the source.
- **`connect`**: a bare host gets port 9559; against a closed port it raises `ConnectionError` after 5 tries with the 0.2 → 1.6 s backoff (sleep patched so the test doesn't wait).
- **`close()`** stops the thread promptly, even mid-backoff.

`tests/test_mock_naoqi.py`: `getTransform` for an effector equals the model's site frame for the set pose, and moves by the injected error.
